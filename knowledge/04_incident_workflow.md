# Регламент обработки инцидента DemoCo (учебный)

## Этапы
1. Зарегистрировать событие, время и сервис.
2. Проверить симптомы, журналы, доступность API и влияние на пользователя.
3. Найти применимую политику рисков.
4. Рассчитать уровень индикатора, если есть числовые данные.
5. Передать результаты человеку на проверку.

## Сроки
При высоком уровне индикатора сформировать запись на эскалацию без автоматического изменения инфраструктуры.

## Ограничения
Не отправлять закрытые данные третьим сторонам без разрешения. Локальный режим демонстрации не делает сетевых запросов к LLM.
